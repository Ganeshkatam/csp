# Survey Charts & Visualizations

This directory is designated for storing charts and diagrams generated from `raw-responses.csv` and `tabulation.csv` for inclusion in the CSP Final Report (`documentation/final-report.md`).

Recommended Charts to Generate:
1. `demographics_occupation.png`: Pie chart or horizontal bar chart showing household occupational distribution (Agriculture, Labor, Artisans, Small Business, Salaried).
2. `digital_connectivity.png`: Bar chart comparing smartphone availability vs internet access types.
3. `scheme_access_challenges.png`: Pareto chart showing major hurdles in accessing government welfare schemes.
4. `emergency_contact_awareness.png`: Stacked bar chart showing percentage of households possessing vs lacking key numbers (PHC, Panchayat, Police, Lineman).
5. `information_priority_ranking.png`: Bar chart of top information categories requested by residents.

Tools for Generating Visualizations:
- Microsoft Excel or Google Sheets (import `tabulation.csv` and export as PNG)
- Python matplotlib / seaborn script if preferred
